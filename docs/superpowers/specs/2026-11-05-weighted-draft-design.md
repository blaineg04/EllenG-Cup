# Weighted two-team draft
Approved intent: use submitted A–D bands, with exact handicaps optional, to balance team strength and depth on every EllenG two-team tournament. Count the captains before ordinary selections, ignore nonplayers, reject missing ranks, and use the same calculation in commissioner, captain and timeout picks.

Implementation choice: band strength units A=5, B=3, C=2, D=1. These are an approximation, not a golf handicap conversion. Enumerate feasible final band allocations respecting existing assignments and snake/straight roster capacities. First minimize the difference in strength per roster place (cross-multiplied integers); then minimize squared band distribution differences. Only selections compatible with at least one optimal completion are eligible. This guarantees the best attainable finish under the stated model without locking the draft when a band cannot divide evenly. Captains remain first-round seeded picks, preserving existing turn order and undo behavior. Existing drafts do not silently change algorithms: commissioner explicitly prepares the weighted draft while paused; ordinary picks beyond the captains prevent conversion. New two-team setups prepare automatically when saved. Other formats retain existing rules and are not silently labeled weighted.

Alternatives: fixed extra-B compensation fails with changing player mixes; exact handicap sums require data users do not have. Chosen weighted bands use the information golfers already submit. Review before production. Do not reset or change live data while developing.
